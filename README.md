# chat

An end-to-end encrypted messenger with group chat, media, location sharing,
1:1 and group video calls, and an optional serverless mode over Bluetooth /
Wi-Fi.

Currently in the **planning phase** — see [`docs/`](docs/README.md) for the
vision, requirements, architecture, and technology decisions.
